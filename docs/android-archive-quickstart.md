# Снимки Android и просмотр архива на Mac

Это инструкция для Android-телефона, подключённого к Mac. `wab-capture` снимает данные телефона в `sources/<устройство>/`; `wab-import` обновляет рабочую папку `wab/<UUID аккаунта>/`. Штатный `wab-viewer` открывает эту папку. Подробности формата приведены в [проектном документе](WAB-Android-Archive-Design.md).

## Установить версию форка отдельно

Нужны Git, Python 3.11+ и Android SDK Platform Tools с командой `adb`. В терминале Mac создайте отдельный checkout и окружение для форка.

```sh
git clone https://github.com/TerminalTitanium/whatsapp-backup-tools.git
cd whatsapp-backup-tools
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
wab-capture --help
wab-import --help
```

## Первые два снимка

Подключите разблокированный телефон по USB и подтвердите отладку. Используйте общий корневой каталог вне Git-репозитория. Старый архив WAB может находиться рядом.

```sh
wab-capture --root "$HOME/WhatsApp-Archive" --device android-phone --account new --account new
```

Программа останавливается для ручного выбора активного аккаунта в WhatsApp и создания резервной копии. Для каждого аккаунта подтвердите назначенный UUID и укажите локальный ключ crypt15. Сохраните два UUID из журнала; в следующих сеансах указывайте их вместо `new`. Адресная книга считывается один раз за сеанс. При переключении аккаунта файлы инвентаризируются заново; сравнение по содержимому занимает время даже при нулевом объёме новой передачи. Команда сохраняет снимки и журнал на Mac. [Подробнее про USB-съёмку](archiver/android-snapshots.md)

## Открыть первый архив

Исходная копия телефона хранится в `sources/`. Для её восстановления нужны база из снимка, соответствующий ключ и версии медиа, перечисленные в его манифесте. В рабочей базе `wab/` пути вложений могут включать хеш содержимого, чтобы просмотрщик различал два файла с одинаковым исходным путём. Для переноса архива вместе с исходниками копируйте обе папки.

Подставьте путь к завершённому снимку и его UUID. Во время полного импорта закройте запущенный просмотрщик этого аккаунта. Для каждого следующего снимка того же аккаунта используйте ту же команду. Полные снимки импортируются в порядке съёмки.

```sh
wab-import "$SNAPSHOT"
wab-viewer "$HOME/WhatsApp-Archive/wab/$ACCOUNT_UUID"
```

Если есть готовый архив v0.80 того же аккаунта, при первом импорте можно использовать `wab-import "$SNAPSHOT" --adopt "$OLD_WAB_ARCHIVE"`. Оператор подтверждает соответствие аккаунта выбором пути. Исходный архив целиком копируется один раз, для этого понадобится место на диске. Закройте его просмотрщик перед копированием. Команда поддерживает обычные локальные файлы. Для существующего архива с символьными ссылками на внешние тома следует начать с нового архива или предварительно собрать отдельную автономную копию.

Новое поколение рабочего архива готовится рядом с действующим. Старые индексные базы копируются в рабочий каталог, неизменяемые вложения связываются жёсткими ссылками. После успешной проверки каталоги атомарно меняются местами. Используйте локальный том macOS или Linux с поддержкой жёстких ссылок и атомарного обмена каталогов. При параллельных запусках импорт одного аккаунта выполняется последовательно. Повторный импорт того же снимка распознаётся по манифесту. Даже если более новый снимок уже импортирован, можно добавить только сведения о контактах из предыдущего.

## Обновить имена и аватарки

Если один из двух аккаунтов уже открыт в WhatsApp на Mac и нужны его аватарки с первого снимка, задайте оба UUID заранее. Команды ниже заменяют первый запуск с двумя `--account new`. В этом примере сначала выберите на телефоне аккаунт, открытый на Mac.

```sh
ACCOUNT_MAC=$(uuidgen | tr '[:upper:]' '[:lower:]')
ACCOUNT_OTHER=$(uuidgen | tr '[:upper:]' '[:lower:]')
ROOT="$HOME/WhatsApp-Archive"
mkdir -p "$ROOT"
python -m shared.mac_avatars --account "$ACCOUNT_MAC" --out "$ROOT/avatar-map-$ACCOUNT_MAC.json"
wab-capture --root "$ROOT" --device android-phone --account "$ACCOUNT_MAC" --account "$ACCOUNT_OTHER" --avatar-map "$ROOT/avatar-map-$ACCOUNT_MAC.json"
```

В следующих сеансах используйте UUID из журнала. Для новой версии аватарок создайте карту под новым именем и передайте её при следующей съёмке. После создания снимка можно применить только изменения контактов и аватарок к уже работающему архиву.

```sh
wab-import "$SNAPSHOT" --metadata-only
```

Эта команда использует уже созданный архив. Имена и фотографии обновляются в индексе без обхода медиакаталога. Пропуск в новой адресной книге сохраняет последнее подтверждённое имя. Просмотрщик подставляет известный номер для контакта без имени. URI профиля или номер сопоставляются отдельно от пути к файлу. [Поиск и привязка аватарок](mac-avatar-map.md)

## Восстановить недостающие вложения

Сначала выполните сверку в режиме отчёта. Только подтверждённые совпадения по хешу могут попасть в комплект восстановления. Применение комплекта к текущему снимку выполняется командой `wab-import "$SNAPSHOT" --repair "$REPAIR_DIR"`. Рабочая база и добавленные файлы изменятся после успешного завершения импорта. [Сверка недостающих вложений](android-media-recovery.md)

Реальные исходники, журналы, ключи, карты контактов и рабочие базы содержат личные данные. Храните их в выбранном локальном корне вне checkout. Если требуется копия на другом диске, копируйте корень после окончания операций записи.
