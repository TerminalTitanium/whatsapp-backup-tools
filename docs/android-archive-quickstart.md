# Снять дамп Android и открыть переписку на Mac

Для выгрузки телефона достаточно одной команды. После неё можно отключить USB, посмотреть, какие базы попали на Mac, и выбрать нужную для архива. Ключ потребуется при подготовке выбранной базы к импорту.

## 1. Установить инструменты

Нужны Git, Python 3.11 или новее и Android SDK Platform Tools с командой `adb`. На Mac откройте Терминал.

```sh
git clone https://github.com/TerminalTitanium/whatsapp-backup-tools.git
cd whatsapp-backup-tools
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
```

Для повторной проверки с чистого листа укажите новый каталог в `--root` и сохраните предыдущий архив вместе с ключами.

Если форк уже установлен из этого репозитория, в его каталоге выполните `git pull --ff-only`, активируйте окружение и повторите `python -m pip install .`. Команда `wab-prepare --help` проверяет, что используется версия с подготовкой баз из дампа.

## 2. Скопировать данные с телефона по USB

Разблокируйте телефон, подключите его к Mac и подтвердите разрешение на отладку по USB. `android-phone-note9` — выбранное имя устройства. Используйте его при следующих выгрузках этого же телефона.

```sh
wab-capture --root "$HOME/WhatsApp-Archive" --device android-phone-note9
```

Команда сохраняет **все файлы из найденных каталогов WhatsApp `Databases`**, в том числе датированные базы, инкременты, `.crypt14` и `.crypt15`. Медиа пополняют общее хранилище устройства. Справочник сохраняется, если телефон разрешил его прочесть. Указывать аккаунт или вводить ключ на этом шаге не требуется.

При первом запуске медиа копируются на Mac. При следующих запусках программа сверяет путь и метаданные и пропускает уже сохранённые файлы. Терминал показывает этап, счётчик файлов и периодические сообщения о ходе работы. Для полной побайтовой сверки всех медиа на телефоне есть отдельный флаг `--verify-media`. Он нужен, например, чтобы обнаружить подмену содержимого с сохранением размера и временных меток.

После `RAW COMPLETE` телефон можно отключить. Для каждой полной crypt15-базы выводится готовая команда `wab-prepare` с её исходным именем и размером. Скопируйте команду нужной базы. При первом запуске введите понятную вам метку аккаунта, затем ключ этой базы. Следом программа напечатает команду импорта, а импорт — команду просмотра. Этот путь работает с пустой папки без предыдущего архива.

В конце выгрузки программа печатает путь к дампу и готовую команду `wab-prepare … --list`. Её можно сразу скопировать в Терминал. Для следующих шагов сохраните путь в переменную `RAW`, подставив имя из вывода.

```sh
RAW="$HOME/WhatsApp-Archive/sources/android-phone-note9/snapshots/<имя-дампа>"
wab-prepare "$RAW" --list
```

Список позволяет увидеть, какие файлы телефон действительно открыл по USB. Одинаковый SHA-256 у нескольких имён означает одинаковое содержимое файлов. Число имён, размер базы и успешная расшифровка сами по себе не определяют владельца. Если нужная база ещё не появилась, переключите аккаунт в WhatsApp, дождитесь создания его локальной копии и повторите `wab-capture`. Первый дамп останется доступен.

## 3. Выбрать базу аккаунта на Mac

В списке `full` обозначает полную базу crypt15, `increment` — её возможное приращение. Строки `full/crypt14 (preserved only)` и `increment/crypt14 (preserved only)` показывают, какие файлы crypt14 сохранены в дампе. Эта команда подготовки работает с crypt15. Метка `unassigned` означает, что владельца файла ещё не указали.

**Если сохранилась известная зашифрованная копия аккаунта**, укажите путь к самому файлу. Программа найдёт совпадение по размеру и SHA-256. При единственном совпадении этой команды достаточно для подготовки. `personal` — пример постоянной метки аккаунта.

```sh
KNOWN='/полный/путь/к/известной-копии.db.crypt15'
wab-prepare "$RAW" --known-backup "$KNOWN" --account personal
```

**Если нужная запись уже опознана**, возьмите её исходный Android-путь из последнего столбца строки `full`. При нескольких копиях известного файла можно добавить к этой команде `--known-backup "$KNOWN"` для проверки выбора.

```sh
DATABASE='<исходный Android-путь из строки full>'
wab-prepare "$RAW" --database "$DATABASE" --account personal
```

При первом запуске введите **один ключ выбранной базы** в скрытом приглашении. Это 64 шестнадцатеричных символа (`0–9`, `a–f`). Чтобы прочитать его с диска, добавьте `--key-file "$KEY_FILE"`. Файл должен содержать только этот ключ одной строкой. Если в вашем `keys.txt` несколько ключей или подписей, используйте скрытый ввод либо сохраните нужную строку в отдельный локальный файл. Проверенный ключ попадает в `key.txt` подготовленного снимка аккаунта.

**Если владелец ещё неизвестен**, сначала сравните выбранную базу с прежней **расшифрованной** копией `msgstore.db` известного аккаунта. Для этого действия укажите файл ключа crypt15 и путь к прежней базе.

```sh
DATABASE='<исходный Android-путь из строки full>'
PREVIOUS_DB='/полный/путь/к/проверенной-копии/msgstore.db'
KEY_FILE='/полный/путь/к/файлу-с-одним-ключом.txt'
wab-prepare "$RAW" --database "$DATABASE" --compare-history "$PREVIOUS_DB" --key-file "$KEY_FILE"
```

`matched_messages` — число совпавших идентификаторов исходящих сообщений в тех же личных чатах, `matched_chats` — число таких чатов. Нулевое пересечение оставляет принадлежность открытой. Сравнение не назначает владельца. После подтверждения подготовьте снимок с постоянной меткой этого аккаунта.

При наличии подтверждённой цепочки инкрементов добавьте отдельный `--increment` для каждого файла по порядку от 1 до N. Полная база и инкременты должны происходить из одного исходного каталога и иметь одинаковую метку поколения в имени (дату, если она есть). Без этого параметра готовится выбранная полная база. Для второго установленного аккаунта повторите подготовку с его базой, ключом и собственной меткой.

## 4. Импортировать и открыть

После подготовки `Account:` показывает постоянный UUID аккаунта, `Prepared snapshot:` — путь к его снимку. Следующая строка уже содержит готовую команду `wab-import` с этим путём. Закройте работающий просмотрщик аккаунта и скопируйте строку целиком в Терминал. Для дальнейших команд ниже можно также сохранить путь из `Prepared snapshot:` в переменную `SNAPSHOT`.

В выводе импорта указан каталог рабочего архива. Подставьте его в `ARCHIVE` и откройте переписку.

```sh
ARCHIVE='/полный/путь/к/рабочему-архиву'
wab-viewer "$ARCHIVE"
```

Новый дамп снова снимается одной командой из шага 2. Подготовка с той же меткой направляет следующий снимок в архив того же аккаунта. Полные снимки импортируются в порядке съёмки. Если есть готовый архив WAB v0.80 этого же аккаунта, при первом импорте можно выполнить `wab-import "$SNAPSHOT" --adopt "$OLD_WAB_ARCHIVE"`. Заранее закройте его просмотрщик и предусмотрите место для одной полной копии.

## Контакты, аватарки и недостающие вложения

- `wab-import "$SNAPSHOT" --metadata-only` обновляет имена и аватарки в существующем архиве без обхода медиа. Если запись исчезла из адресной книги, просмотрщик сохраняет последнее известное имя.
- Аватарки из WhatsApp на Mac можно добавить к снимку при подготовке. Передайте карту через `wab-prepare … --avatar-map "$AVATAR_MAP"`. Для её составления используйте UUID из строки `Account:`. [Как составить карту аватарок](mac-avatar-map.md)
- Вложения, сохранившиеся на Mac, можно сверить с базой и восстановить по подтверждённому хешу. [Как восстановить недостающие файлы](android-media-recovery.md)

Для переноса всей коллекции после окончания записи скопируйте обе папки, `sources/` и `wab/`. В исходниках лежат в том числе ключи. Журнал каждой выгрузки и состав сырого дампа описаны в [справке по USB](archiver/android-snapshots.md).
